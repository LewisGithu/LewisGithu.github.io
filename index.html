YouTube Channel Performance Engine

Problem: Evaluating creator engagement across a growing video catalog is time-consuming when content formats and featured vehicle models are buried inside unstructured titles and metadata.
Solution: Engineered an automated end-to-end pipeline that extracts channel metrics (videos, views, likes, comments) via the YouTube Data API and uses Google Gemini AI in Databricks to automatically classify video formats and featured car models.
Tools: YouTube Data API v3, Python, PySpark, Databricks (ai_parse / Google Gemini), Databricks SQL, Pandas, Tableau.
Result: Built an interactive, long-form Tableau Dashboard that uncovered key content drivers—showing that road trip videos generate 40% higher average watch times than standard car reviews and BMW M3 features drive the highest comment engagement ratio.

Rumble Channel Analytics & Medallion ETL

Problem: Dynamic JavaScript rendering and anti-bot firewalls prevent standard HTTP requests from extracting livestream performance metrics on Rumble.
Solution: Built a two-stage local scraping pipeline using Playwright to capture rendered DOM snapshots across paginated livestream pages and BeautifulSoup to parse custom HTML5 web components (<rum-video-thumbnail>), then processed the data through a Bronze-Silver-Gold Medallion architecture in Databricks with AI topic classification.
Tools: Python, Playwright, BeautifulSoup4, Pandas, Databricks (Delta Lake, PySpark, SQL, AI/BI Dashboards).
Result: Delivered a curated Gold analytical layer and interactive Databricks BI Dashboard revealing that livestreams over 2 hours consistently generate higher total views and stronger comment-to-view ratios, while scheduled evening broadcasts drive peak view velocity within the first 24 hours.

Cryptocurrency Live Market Pipeline & Dashboard

Problem: Tracking real-time price fluctuations across top cryptocurrencies requires automated ingestion and flattening of nested API JSON payloads rather than static spreadsheets.
Solution: Developed an automated Python data pipeline with header authentication and error handling to pull live market snapshots at regular intervals, normalize nested JSON responses into structured DataFrames, and power a live multi-currency web app.

DataBricks Murang'a County Government Performance Project

Problem: Comparing county project delivery across administrations (2013–2026) meant dealing with messy public spreadsheets and double-counted budgets on shared ward projects.
Solution: Cleaned the official county records in Databricks, split shared budgets fairly across wards and partners, and matched each governor's first four years for a fair comparison.
Tools: Databricks (Unity Catalog, Delta Lake, AI/BI Dashboards, Genie AI Workspace, SQL), Python, YAML Metric Views.
Result: Built an executive dashboard that flagged 29 stalled projects, exposed zero-spend reporting gaps, and showed that both administrations achieved ~85% completion and ~70% spend efficiency despite contrasting strategies (86 large projects under Wa Iria vs. 781 smaller community projects under Kang'ata).
